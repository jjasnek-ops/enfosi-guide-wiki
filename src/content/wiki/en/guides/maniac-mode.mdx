## What is officially confirmed about Maniac?

The current [Roblox listing](https://www.roblox.com/games/78353262320982/Enfosi) describes SMILE MORE as a game overhaul with new content and a new Maniac difficulty. It also describes the same statue-defense objective, disguised enemies, wave introductions, bosses, equipment and classes.

That description establishes the difficulty’s existence. It does not establish a precise unlock route, enemy health table, wave schedule or reward multiplier. Those details remain unverified here.

## How should you prepare for an attempt?

1. Complete the learning loop in the [beginner guide](/guides/beginner-guide/): find the objective, inspect arrivals, use your tools deliberately, and review one mistake.
2. Read the [disguise checklist](/guides/spot-fakes/) with its source limits. Do not bring an absolute rule from an older difficulty into an unfamiliar mode.
3. Read your current class and item descriptions using the [class comparison checklist](/guides/classes/).
4. Agree who will watch the approach when others engage. Use the [statue-defense routine](/guides/statue-defense/) as a starting habit.
5. Check the actual difficulty option and any displayed restriction in the current lobby.

These are preparation recommendations. They are not a game-defined unlock procedure.

## Which old advice needs another check?

Be careful with articles that assign an exact wave number to every boss, list older equipment names, or publish damage values without a difficulty and version. The [SMILE MORE summary](/updates/smile-more/) separates the official overhaul announcement from the date on which the game’s metadata last changed.

If your lobby or run differs from the linked footage, keep the current UI as the basis for the attempt. A useful correction report includes the difficulty, modifiers, version context, and a public timestamp showing the discrepancy.

## What still needs evidence?

Current Maniac unlock requirements, a complete boss schedule, exact scaling and rewards all require further verification. They are held for a later update rather than filled from an earlier-version wiki.

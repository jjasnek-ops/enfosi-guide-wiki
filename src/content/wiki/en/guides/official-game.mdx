## How can you verify the creator?

Follow the creator shown on the official game page. Roblox’s [public Tumore group metadata](https://groups.roblox.com/v1/groups/9835935) names Enfosi in the group description and identifies BucketBazard as the group owner.

## Which device should you use?

The current developer description recommends PC. It says other devices work but are not the intended setup. That statement is a recommendation, not a promise that every touch or controller interaction matches PC.

This site has not tested the game on mobile or verified every current key binding. Once you can launch the intended experience, use the [beginner guide](/guides/beginner-guide/) to learn the objective and first-run sequence.

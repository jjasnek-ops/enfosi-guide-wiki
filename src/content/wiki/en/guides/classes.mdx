## What class names can you look for?

The developer confirms that classes change how you play. The browser-read [community playable reference](https://enfosi.fandom.com/wiki/Glaggles_(Playable)) lists the following names. Its purchasable/special distinction is **community documentation**, not an independently tested account-unlock record.

| Community entry | Where the reference lists it | What to verify in-game |
|---|---|---|
| Giggler | Purchasable classes section | Current starting loadout and perks |
| Gazo | Purchasable classes section | Equipment benefits and restrictions |
| Gloober | Purchasable classes section | Current tool descriptions and tradeoffs |
| Gembo | Purchasable classes section | Current weapon behavior and penalties |
| Cheerer | Purchasable classes section | Current equipment interactions |
| Gleeber | Purchasable classes section | Current movement/tool behavior |
| Glaaber | Purchasable classes section | Current restrictions and equipment |
| Sobber | Other classes section; described as special | Availability and unlock route, unverified here |

This distinction explains why a page can say “seven classes” while another lists eight playable characters. Do not assume an old seven-entry chart is the complete current roster.

## What should you read before choosing?

Read both the benefit and the restriction. In [SMILE MORE Maniac footage](https://www.youtube.com/watch?v=RzjdxqnRNXU&t=183s), the shop at **3:03–3:20** shows Gembo’s equipment and an individual Dareblade description. The filmed menu supports checking the current item panel; it does not prove every class’s present statistics.

Compare these questions:

1. What tools does this selection actually give you?
2. Which equipment does the current perk panel help or restrict?
3. Does the choice make your current problem easier to practice?
4. Can you use the equipment while still watching the statue?
5. Are you following advice from the same version and difficulty?

The [SMILE MORE update summary](/updates/smile-more/) explains why older names and numbers require another check.

## How can you choose without a tier list?

Name the problem first. If you keep misreading arrivals, a more specialized class does not establish a better identification rule; use the [disguise guide](/guides/spot-fakes/). If you keep leaving the objective uncovered, practice the [defense routine](/guides/statue-defense/).

Then test one class with one goal. Compare what helped and what became harder. This is a learning method, not a claim that a particular class wins more often. For a new player, the [beginner guide](/guides/beginner-guide/) puts equipment selection in the context of a complete run.

## What is deliberately missing from the comparison?

There are no damage scores, purchase prices, cooldown tables or S–F rankings here. The current values were not independently verified. Sobber’s unlock route and any newer playable entries also need current footage or an official explanation before publication.
